## 1. Title screen and front-end flow (`TITLE.tr2` and `TOMBPC.DAT`)

### Startup sequence and title presentation

| Stage | Established retail PC behaviour |
|---|---|
| Launch and script load | **Established (static).** On startup, the game loads `data\tombPC.dat` (script format version `3`, string XOR obfuscation key `0xa6`, global flags `0x0300`: string obfuscation enabled and Lara's Home enabled), binds menu labels from the script's 89 game strings and 41 PC strings, initializes audio, seeds default campaign start records (24 slots `0..23`, marking only level `0` Lara's Home and level `1` The Great Wall available), scans existing save slots (`0..15`, preselecting the slot carrying the highest monotonic save counter), and loads user settings. |
| Legal splash and front-end movies | **Established (static).** Displays static image `data\legal.pcx` (30-frame fade-in, 90-frame / 3.0 s wait skippable by keyboard input, 12-frame fade-out), then runs the front-end script sequence: two consecutive FMVs, `FMV\LOGO.RPL` (movie slot `0`) and `FMV\ANCIENT.RPL` (movie slot `1`). Quitting during the movies exits the application; otherwise the front end enters the script's initial option (`0x0500`, Title Screen). |
| Title level (`TITLE.tr2`) versus backdrop (`title.pcx`) | **Established (static).** Entering the title screen loads `data\title.TR2` once if not already loaded (format version `45`, 3 texture pages, 2 rooms). Unlike later Tomb Raider titles, **Tomb Raider II has no 3D camera flyby loop on the title screen**: `TITLE.tr2` supplies only the 3D inventory-ring object models, meshes, and textures, while the backdrop is the static image `data\title.pcx` drawn behind the interactive 3D ring. |
| Title music | **Established (static).** Because the script's title track is nonzero (`64` in retail `TOMBPC.DAT`), entering the title screen starts looping CD playback of logical track `64` (mapped to physical PC CD track `60` by skipping virtual indices `{2, 19, 20, 26}`). While the title ring runs, the periodic loop poll checks playback every `150` ticks (initialized at `120`, so first check occurs after `30` ticks) and restarts the track if stopped. Leaving the title screen stops music and fades to black. |
| Title ring composition and initial focus | **Established (static).** In retail PC Tomb Raider II, the title ring contains **4** items in cyclic order: index `0` **Passport** (object `133`, label `Game`), index `1` **Controls** (object `155`, label `Controls`), index `2` **Sound** (object `154`, label `Sound`), and index `3` **Polaroid** (object `122`, label `Lara's Home`). Retail PC has **no** Detail Levels item on the ring (in gameplay the option ring omits the Polaroid and has 3 items: Passport, Controls, Sound). On the very first entry to the title screen after launch (when Load/Save is not disabled and Lara's Home is enabled), initial focus starts on index `3` (**Lara's Home** Polaroid); once the player leaves the title screen for gameplay or Lara's Home, every subsequent return focuses index `0` (**Passport**). |
| Title ring selection outcomes | **Established (static).** Selecting **Polaroid** (`122`) starts Level `0` (`data\assault.TR2`, Lara's Home) when the Home flag (`0x0200`) is enabled. Selecting **Passport** (`133`) opens the passport pages: Page `0` (`Load Game`) clears carried items, loads the chosen save slot `0..15`, and enters that level in saved-game mode; Page `1` (`New Game`) resets campaign start slots (unless Bonus Mode is active) and starts Level `1` (`The Great Wall`), or starts the chosen level `1..18` when the select-any-level script flag (`0x0400`) is enabled; Page `2` (`Exit Game`) terminates the application. Selecting **Controls** (`155`) or **Sound** (`154`) opens its configuration overlay and returns to the open title ring when confirmed or cancelled (never leaving the title screen). Pressing Deselect or Inventory/Option on the open title ring is ignored. |
| Idle demo timer and demo cycle | **Established (static).** Retail `TOMBPC.DAT` sets idle timeout `900` ticks (30.0 s at 30 Hz), `3` demo levels `[19, 20, 21]` (Venice, Wreck of the Maria Doria, Tibetan Foothills), and clears the global in-game idle-timeout flag (`0x0008`). On the title screen, because at least one demo level is configured, every frame with zero live and debounced input increments the idle counter; any input resets it to `0`. When the counter strictly exceeds `900` (`> 900`), the title ring closes automatically and launches the next demo in cyclic order (`19` → `20` → `21` → `19`). Each demo seeds both random number generators to the fixed startup seed, loads its level in demo mode, temporarily grants full all-weapons cheat stock (backing up and restoring that slot's start record afterward), and replays recorded inputs. Any player input during a demo (`0x0500`), reaching end of demo input (`0x0500`), or Lara dying during a demo (`0x0500`) immediately returns to the title screen. |

### Complete `TOMBPC.DAT` campaign script sequence

**Established (static).** Retail `TOMBPC.DAT` (`Final Release Version 1.1`) defines 22 level entries (`0..21`: training home `0`, 18 campaign levels `1..18`, and 3 demo replays `19..21`), 4 in-engine cutscenes (`0..3`: `data\cut1.TR2` through `data\cut4.TR2`), 8 FMVs (`0..7`), title track `64`, global secret chime track `47`, campaign mode (no single-level lock), and hardcoded post-level statistics music track `41`.

Script event kinds used across the retail campaign:
- Kind `3` (Play FMV): plays movie slot `0..7` (skipped when resuming from a saved game).
- Kind `4` (Start Level): enters playable level slot `N`; when resuming from a saved game, transitions from saved-game mode to normal mode upon completion so post-level events run normally.
- Kind `5` (Cutscene): plays in-engine cutscene slot `0..3` (skipped when resuming a saved game before the playable level; runs normally after a loaded level finishes).
- Kind `6` (Level Complete): displays Level Statistics (track `41`), records carried stock for level `N + 1`, clears level `N`'s available bit, and advances to level `N + 1`.
- Kind `7` (Demo Play): starts recorded demo playback for demo slot `N`.
- Kind `10` (Set Track): selects the next audio track (first entry before Start Level sets the level's looping ambient track, `0` = silence; entries after Start Level set the subsequent cutscene or credits track).
- Kind `11` (Sunset): enables progressive sunset lighting shift over gameplay time.
- Kind `13` (Deadly Water): records the deadly-water script flag (`1`).
- Kind `14` (Strip Weapons): removes all owned weapons and resets weapon choice to unarmed on normal level entry (skipped on saved-game reload).
- Kind `15` (Game Complete): runs the credits slideshow (`data\credit01.pcx`..`credit09.pcx` with track `52`), displays Final Statistics, unlocks Bonus Mode, and returns to Title.
- Kind `16` (Cut Angle): sets cutscene anchor rotation angle (default `16384` = 90° if omitted; `0` when explicitly authored).
- Kind `17` (Lethal Bottom Plane): sets lethal bottom-Y kill threshold (`Lara.Y ≥ value`).
- Kind `18` (Inventory Grant): operand `< 1000` is a **3-dragon secret reward** entry; operand `≥ 1000` is a **level-start grant** (`operand − 1000`, skipped on saved-game reload). Item indices: `0` Pistols, `1` Shotgun, `2` Automatic Pistols, `3` Uzis, `4` Harpoon Gun, `5` M16, `6` Grenade Launcher, `7` Pistol Ammo, `8` Shotgun Ammo (`12` pellet units / 2 shells), `9` Automatic Pistol Ammo (`40`), `10` Uzi Ammo (`80`), `11` Harpoons (`3`), `12` M16 Ammo (`40`), `13` Grenades (`2`), `14` Flares (box of `6`), `15` Small Medikit, `16` Large Medikit, `17..18` Pickups `1..2`, `19..22` Puzzles `1..4`, `23..26` Keys `1..4`.
- Kind `19` (Start Animation): starts Lara in the named extra-animation state (`8` or `9`) under a cinematic camera on normal level entry (skipped on saved-game reload).
- Kind `20` (Secret Count): overrides the expected secret count for the level (default `3`; set to `0` where no dragons exist).
- Kind `21` (Strip Ammo and Consumables): clears all ammo reserves, flares, and medikits on normal level entry (skipped on saved-game reload).
- Kind `22` (Kill to Complete): flags the level as the kill-all epilogue encounter.

## 2. Death and retry flow

### Death initiation, timer progression, and context-specific behaviour

| Aspect | Established retail PC rule |
|---|---|
| First tick at `HP ≤ 0` | **Established (static).** Whenever Lara's health is nonpositive (`≤ 0`) at the start of her per-tick update, health clamps to `−1`. If the death timer is still `0`, CD music stops immediately (once only). The death timer then increments by `+1` on every tick. |
| Obliterated / vanished Lara (`+2/tick`) | **Established (static).** If Lara has invisible status set (for example after being obliterated by an aquatic mine or removed by a fatal hazard), the death timer increments a **second** time on the same tick (`+2` per tick total, halving the real-time wait) and Lara's water and movement updates are skipped for that tick. |
| Scripted bottomless-fall kill (kind `17`) | **Established (static).** When the level's scripted bottom plane is nonzero (e.g., `9728` in Floating Islands) and Lara is still alive (`HP > 0`) with `Lara.Y ≥ threshold`, health immediately becomes `−1` and the death timer initializes to **`270`** ticks (9.0 s). Because the timer begins at `270`, automatic menu opening occurs after only `31` additional ticks (~1.0 s) and any input triggers the death menu on the very next tick (since `270 > 60`). |
| Ground, air, and wading death | **Established (static).** On land or wading, `HP ≤ 0` transitions Lara into ground death state (`8`), which clears hit and baddie-push flags, stops the falling scream sound, aligns Lara to the floor with expanded collision radius (`400`), keeps health at `−1`, and sets air to `−1`. A lethal fall impact (vertical speed `> 154`) requests state `8` directly on landing; spike impalement zeroes fall speed on frame `1` of the spike-death clip. |
| Underwater / drowning death | **Established (static).** Submerged air starts at `1800` (60 s) and decreases by `1` per tick; once air becomes negative it clamps to `−1` and health decreases by `5 HP/tick`. At `HP ≤ 0`, underwater states request underwater death state (`30`): gravity clears, swim speed decelerates by `8` per tick down to `0`, pitch levels toward `0°`, air stays `−1`, hands become occupied, and whenever a water surface lies more than `100` units above Lara (`waterHeight < Lara.Y − 100`), she drifts upward by `5` units per tick. |
| Surface death | **Established (static).** At the water surface, air regenerates `+10` per tick (capped at `1800`) only while `HP ≥ 0`. If killed while at the surface (e.g., by gunfire, flames, or hazards), health clamps to `−1` and the death timer advances identically. |
| Speedboat and snowmobile death | **Established (static).** While riding the speedboat (`type 14`), `HP ≤ 0` overrides steering and dismount inputs, immediately placing Lara into boat-rider death state (`8`, vehicle base clip `+18`). While riding the snowmobile (`type 13`), `HP ≤ 0` clears directional drive inputs (forward, back, left, right) and transitions Lara into the snowmobile death state. |
| Fire and lava death | **Established (static).** An attached flame deals `7 HP/tick` (continuing even when `HP ≤ 0`) and extinguishes only when its attached joint Y drops strictly below a water surface. Stepping on true-floor deadly lava kills immediately and attaches up to 10 flame effects. |
| Special creature fatal takeovers | **Established (static).** Fatal grapple attacks by the Tyrannosaurus, Shark, or Yeti switch Lara to the auxiliary extra-animation model (`type 12`), snap her position, orientation, and room to the attacker, occupy her hands, disable normal controls and inventory, and apply dedicated camera overrides (`160°` yaw and `3072` distance for Shark and Yeti; `170°` yaw and `−25°` elevation for Tyrannosaurus). |
| Death timer thresholds (auto vs early input) | **Established (static).** The death transition fires at the start of a gameplay tick whenever **either**: (a) the death timer strictly exceeds `300` (tick `301` = 10.03 s automatically with no input), **or** (b) the death timer strictly exceeds `60` (tick `61` = 2.03 s) **and** any mapped input bit is active (any gameplay or menu key/button qualifies — not restricted exclusively to Action or Inventory). |
| Outcome by mode and two-tick HUD hide | **Established (static).** Once either threshold is satisfied: (1) in **Demo mode**, immediately returns to Title (`0x0500`); (2) in **Lara's Home** (Level `0`), immediately returns to Title without opening the Passport; (3) in **campaign levels (`1..18`)**, the first qualifying tick switches the HUD overlay into hide-pending state so one clean frame renders without HUD, and the following tick restores overlay status and opens the Passport in **Death mode (`mode 5`)**. |
| Camera behaviour during death | **Established (static).** Ordinary ground (`state 8`) and underwater (`state 30`) deaths impose **no** special death-camera mode: the standard chase camera continues tracking Lara's dead body bounds and origin normally unless overridden by an active fixed/heavy trigger camera or a special-takeover extra animation. |

### Passport pages and options across all modes

The Passport (`object 133`) presents 3 pages indexed by its open animation frames (`page = (targetFrame − 14) / 5`, valid pages `0`, `1`, `2`; turning pages plays sound `115`). Up to `16` save slots (`0..15`) exist, presented in a scrolling 10-line list displaying each saved level title and monotonic save counter (or `- EMPTY SLOT -`).

Falls back to normal ring if Load/Save is disabled (`0x0010`). |

## 3. Level-end statistics, transitions, and inter-level carry

### Level-completion triggers and post-level stage order

| Trigger or stage | Established retail PC rule |
|---|---|
| Floor trigger action `7` (Finish Level) | **Established (static).** Sets the level-complete flag during floor-trigger evaluation. Does not interrupt the rest of the current trigger list or tick: Lara's movement, camera, sound effects, and elapsed clock complete that tick, and the gameplay loop exits at the start of the next tick. |
| Effect `4` (Finish Level effect) | **Established (static).** Floor-triggered effect action `9` with argument `4`, or animation-command effect `4`, sets the level-complete flag when executed in the post-camera effects pass. |
| Home Sweet Home epilogue (`object 254` + kind `22`) | **Established (static).** In Level `18` (`Home Sweet Home`), the combat-end controller (`object 254`) counts all remaining live hostile creatures other than the Shotgun Boss (`object 24`). Once all ordinary enemies are dead, it activates the Shotgun Boss. Once both all ordinary enemies and the Shotgun Boss are dead, it counts `150` ticks (5.0 s), clears any held flare, vehicle, or weapon meshes, transitions Lara into the final shower extra animation under an in-level cinematic camera, plays the bath audio track, equips the shotgun mesh at frame `316`, and sets the level-complete flag on the final frame of the clip. |
| Level-skip cheat (reference) | **Established (static).** When cheat detection is enabled (levels `1..17` only; disabled in Level `0` and Level `18`), performing the classic step/spin/jump-with-flare sequence sets the level-complete flag. |
| Completion in Lara's Home (`level 0`) | **Established (static).** If level completion fires in Level `0`, the screen fades to black and returns directly to Title without showing Level Statistics. |
| Post-level transition order (`levels 1..17`) | **Established (static).** After leaving the gameplay loop: (1) stops all sound effects and CD music and restores full music volume; (2) fades into the transition backdrop; (3) runs any post-level in-engine cutscene (kind `5` with track kind `10` and angle kind `16`; skippable by held Action, or held Inventory when not suppressed); (4) displays **Level Statistics** (kind `6`, playing track `41` non-looping, dismissed by pressing Select/Action after releasing any previously held Select); (5) archives level `N`'s 7 statistics into level `N`'s campaign slot, snapshots carried inventory into level `N + 1`'s campaign slot, advances current level to `N + 1`, marks level `N` unavailable, and fades to black; (6) plays any inter-chapter FMV (kind `3`); (7) begins Level `N + 1`. |
| Final level completion (`level 18`, kind `15`) | **Established (static).** After `Home Sweet Home` completes: fades to black, loads `TITLE.tr2`, plays track `52` non-looping across the 9-slide credits sequence (`data\credit01.pcx`..`data\credit09.pcx`), then shows **Final Statistics** (dismissed by Select/Action). On dismissal, enables **Bonus Mode (New Game Plus)**, seeds all campaign slots `1..21` with Bonus Mode stock, resets current level to `1`, and returns to Title. |

### Statistics fields, accumulation rules, and exact display formatting

All 7 statistics live in the active level's statistics record (zeroed at every normal level entry, preserved across mid-level save/load, and archived into the completed level's campaign slot when Level Statistics or Final Statistics opens). During gameplay, selecting the **Stopwatch** (`object 121`, label `Statistics`) on the main ring displays the identical 7-row statistics box with a live-ticking clock (or **BEST TIMES** for the obstacle course in Lara's Home).

| Display label | Accumulation rule | Units & exact formatting |
|---|---|---|
| **Time Taken** | **Established (static).** Increments `+1` at the end of every 30 Hz gameplay tick in levels `1..18` (and in Level `0` only while the assault-course timer is active). **Also** advances at 30 Hz (integer floor of elapsed 60 Hz menu ticks divided by 2) while the in-game inventory ring is open in levels `1..18`. | Stored as unsigned 32-bit ticks at 30 Hz. Formatted as zero-padded `HH:MM:SS`: `hours = ticks / 108000`, `minutes = (ticks / 1800) mod 60`, `seconds = (ticks / 30) mod 60` (all integer division truncating toward zero). The assault-course HUD timer formats `MM:SS.d` with `deciseconds = (ticks mod 30) / 3`. |
| **Secrets Found** | **Established (static).** 3-bit mask: bit `0` (`0x01`) = Gold Dragon (`type 190`), bit `1` (`0x02`) = Jade Dragon (`type 191`), bit `2` (`0x04`) = Silver/Stone Dragon (`type 192`). Acquiring any dragon sets its bit and plays track `47` (non-looping); when all 3 bits are set (`3` distinct dragons), immediately grants that level's secret-class (`< 1000`) script rewards with pickup display icons. | Row is **omitted** when expected secret count is `0` (levels `0`, `17`, `18`). On per-level stats: if mask is `0`, displays `None`; otherwise displays 3 fixed icon slots in order (bit `0` glyph, bit `1` glyph, bit `2` glyph, substituting 3 spaces for each missing dragon). On **Final Statistics**: sums collected dragon bits across levels `1..16` (excluding levels `0`, `17`, `18`, and demos) and formats `<total> of 48` (3 per level × 16 levels). |
| **Kills** | **Established (static).** Increments `+1` whenever ordinary weapon damage reduces a creature's health from strictly positive (`> 0`) to `≤ 0`. **Retail PC grenade quirk:** a grenade detonation that reduces a creature's health from `> 0` to `≤ 0` applies both the standard fatal-hit increment (`+1`) and an additional blast-kill increment (`+1`) whenever the target's resulting health is `≤ 0`, causing fatal grenade hits to add **`+2`** Kills in retail PC. For the Dragon (`type 203`), reducing health to `≤ 0` triggers temporary collapse (adding `+1` Kill); if Lara does not pull the Dagger of Xian before revival, it revives at `300` HP and can be downed again. | Stored as unsigned 16-bit integer. Formatted as a plain decimal integer. |
| **Ammo Used** | **Established (static).** Increments `+1` per individual weapon discharge: Pistols, Automatic Pistols, and Uzis `+1` per firing hand (`+2` for a simultaneous double-hand discharge); **Shotgun `+6` per shell** (hitscan discharge evaluates 6 times, once per pellet); M16 `+1` per fired bullet; Harpoon Gun `+1` per launched bolt; Grenade Launcher `+1` per launched grenade; Armed Snowmobile `+1` per gun shot. | Stored as unsigned 32-bit integer. Formatted as a plain decimal integer. |
| **Hits** | **Established (static).** Increments `+1` for each qualifying creature hit: each hitscan bullet or pellet intersecting a target creature sphere (`+1` per hitting pellet for Shotgun, up to `+6` per shell), each harpoon bolt hitting a creature, and each grenade blast hitting an active intelligent creature. Shooting breakable windows (`type 72`/`73`) or the shootable bell without hitting a creature does **not** increment Hits. | Stored as unsigned 32-bit integer. Formatted as a plain decimal integer. |
| **Health Packs Used** | **Established (static).** Increments `+1` when using a Small Medikit (`+500` HP, capped at `1000`) and `+2` when using a Large Medikit (`+1000` HP, capped at `1000`). Both require `0 < Lara.HP < 1000`; attempting to use either at full health (`1000`) or while dead (`≤ 0`) consumes nothing and adds `0`. | Stored as an 8-bit integer count of half-pack units. Formatted as `<units / 2>.0` when even, or `<units / 2>.5` when odd. |
| **Distance Travelled** | **Established (static).** At the end of every Lara update tick, adds `floor(sqrt((X − prevX)² + (Y − prevY)² + (Z − prevZ)²))` (3D Euclidean displacement in world units) and records the new origin as previous position. | Stored as unsigned 32-bit world units. Converted to meters via integer division `meters = distance / 445`. If `meters < 1000`, formatted as `<meters>m`; if `meters ≥ 1000`, formatted as `<meters / 1000>.<two-digit(meters mod 100)>km`. (**Retail PC quirk:** the two-digit decimal prints `meters mod 100`, not `(meters mod 1000) / 10`.) |

### Inter-level carry, resets, and special script overrides

| Category | Normal transition (`Level N → Level N + 1`) | Special overrides & notes |
|---|---|---|
| **Weapons owned** | **Established (static).** Carried from `N` to `N + 1` (Shotgun, Automatic Pistols, Uzis, Harpoon Gun, M16, Grenade Launcher). **Retail PC start-slot rule** *(superseding the informal "selected weapon" summary in `tr2-bartoli-and-weapons.md` §4)*: normal level entry always forces Pistols owned, pistol reserve `1000`, and selected weapon = **Pistols (`1`)** before script overrides run — even if Lara finished Level `N` with a different gun selected (unless Strip Weapons immediately clears them). | **Level `0` (Home):** all weapons cleared, unarmed. **Level `1` (Great Wall):** Pistols + Shotgun. **Level `5` (Offshore Rig) & Level `18` (Home Sweet Home):** Strip Weapons (kind `14`) clears all weapon ownership including Pistols and sets weapon to Unarmed (`0`). |
| **Ammunition reserves** | **Established (static).** For every owned gun, the exact live internal reserve carries over (Shotgun in pellet units, 6 per shell; all others in rounds, bolts, or grenades). For every unowned gun, loose ammo bundles in the main ring are archived as `bundles × packSize` (`40` Auto, `80` Uzi, `12` Shotgun, `3` Harpoon, `40` M16, `2` Grenade) and restored on entry as `reserve / packSize` loose bundles (integer division truncating any sub-pack remainder). Any uncollected world placement of an already-owned gun in Level `N + 1` is replaced on load with its matching ammo pickup. | **Level `5` (Offshore Rig):** Strip Weapons runs **without** Strip Ammo, so all carried ammo reserves survive and convert into loose main-ring bundles (truncated to whole packs) until each gun is recovered. **Level `18` (Home Sweet Home):** Strip Ammo (kind `21`) zeroes all ammo reserves. |
| **Flares and medikits** | **Established (static).** Unspent inventory flares, Small Medikits, and Large Medikits carry over exactly. A burning flare still held in Lara's left hand on the level-finish tick is **not** refunded into inventory. | **Level `0` (Home):** zeroed. **Level `1` (Great Wall):** `2` flares, `1` small, `1` large. **Level `18` (Home Sweet Home):** Strip Ammo/Consumables (kind `21`) zeroes flares, small medikits, and large medikits. |
| **Keys, puzzles, pickups, secrets** | **Established (static).** Never carried between levels. All key-ring entries and dragon secret bits reset to `0` on every new level entry. | Start-class script grants (kind `18`, operand `≥ 1000`) apply after inventory setup on normal entry only (skipped on saved-game load): `The Seraph` (Puzzle 4) in Levels `11` and `12`; `Gun Cupboard Key` (Key 1) in Level `18`. |
| **Lara vitals, pose, and hands** | **Established (static).** Reset on every new level entry: `HP = 1000`, `air = 1800`, hands free (`0`, holstered), death timer `0`, burning off, unmounted (`−1`), no auxiliary weapon item (`−1`), no combat target, flare age `0`, flare left-hand control off, climbing off, extra-animation off. Pose initializes at the authored spawn placement: dry standing (`clip 11`, state `2`) if the spawn room is dry, or submerged tread (`clip 108`, state `13`) if the spawn room is underwater. | **Start Animation (kind `19`):** in Level `5` (`state 8`) and Level `18` (`state 9`), normal level entry starts Lara on auxiliary model `12` in extra-animation mode with occupied hands and cinematic camera anchored at Lara's spawn pose. |
| **World & campaign statistics** | **Established (static).** The active level's 7 statistics reset to `0` (completed levels' archived statistics remain in their campaign slots for Final Statistics). Flipmap status (`0`), all 10 flipmap slot masks (`0`), active flip effect (`−1`) and timer (`0`), all 64 CD track flag words (`0`), fixed camera one-shot flags (`0`), monk hostility (`0`), active effects, and thrown world flares all reset. | The level's configured ambient track starts looping if nonzero. |
| **Bonus Mode (New Game Plus)** | **Established (static).** Unlocked upon dismissing Final Statistics (kind `15`). While active, selecting New Game skips clearing campaign start records; every non-Home level starts with all 7 weapons owned, **Grenade Launcher (`6`)** selected, `10001` internal units in all 6 finite reserves, and `255` flares. While Bonus Mode is active, firing never depletes finite reserves (hitscan resets finite reserves to `1000` before spending `1`; harpoon and grenade skip decrement), and HUD/inventory ammo numbers are hidden. | Disabled in Lara's Home (`level 0`). |

## 4. Save / load persistent state contract (behavioural)

This section specifies **what gameplay state MUST be saved and restored** for an exact mid-level Tomb Raider II resume, independently of any binary file layout.

### Mandatory persisted state checklist

| Subsystem | Required persisted state & restoration semantics |
|---|---|
| **Campaign & level metadata** | **Established (static).** Active level ID (`1..18`); Bonus Mode flag; all 24 campaign start records (preserving completed levels' archived 7-field statistics for Final Statistics, plus the current level's inventory snapshot); the active level's 7 live statistics (elapsed ticks, ammo used, hits, distance, kills, dragon secret bitmask, half-medikit count). |
| **Inventory & key ring** | **Established (static).** Owned weapon flags (all 7 guns), live ammo reserves for owned guns or loose bundle counts for unowned guns, unspent flares, Small Medikits, Large Medikits, remembered weapon (previous gun if currently holding a flare, otherwise current gun), plus carried counts of Pickup `1..2`, Puzzle `1..4`, and Key `1..4`. On restore, the main and key rings are rebuilt from these counts (replacing uncollected world placements of owned guns with ammo pickups), and level-start script grants (`≥ 1000`) and weapon/ammo strip flags are **not** re-applied. |
| **Player (Lara) core state** | **Established (static).** World position `(X, Y, Z)`, orientation `(pitch, yaw, roll)`, current room, horizontal speed, vertical fall speed; current state, goal state, required state, animation clip, frame number; hitpoints; item active, status, gravity, collidable, and trigger flags; hand status (`0..5`), active weapon type, requested weapon type, remembered weapon type; water status (`0..4`), water-surface distance, air (`−1..1800`), dive counter; climb status, idle-pose counter, directional hit frame and hit direction, recorded fall speed for landing-impact evaluation, death timer, current underwater sink target, hit-spasm counter, turn rate, movement angle, previous-tick position (for distance accumulation); head `(X, Y, Z)` and torso `(X, Y, Z)` rotations; mounted vehicle item index (`−1` if unmounted); back-holstered long-gun type; held flare age, flare animation frame, left/right flare-control flags; extra-animation flag, look-permitted flag, burning flag, mesh-effect bitmask, all 15 active body mesh selections; both left and right arm animation states (arm model/clip number, frame number, target lock, `(X, Y, Z)` aim angles, muzzle-flash counter); live ammo reserves for all 7 weapons. On restore: transient combat target, spasm effect, and any active creature-AI / grapple reference clear to none; if the burning flag is set, it clears and immediately re-attaches a live flame effect to Lara. |
| **Drawn long-gun auxiliary item** | **Established (static).** Whenever Lara has an active auxiliary long-gun item (while drawing, aiming, or holstering Shotgun, M16, Harpoon Gun, or Grenade Launcher), persist its object type, animation clip, frame number, current state, and goal state. On restore, recreate the active auxiliary weapon item (no room, `255`) attached to Lara. |
| **World environment flags** | **Established (static).** Current room-flip status (`0` unflipped, `1` flipped — if `1` on restore, perform the room flip **before** restoring items so alternate-room geometry and item floor adjustments match); all 10 flipmap slot masks (5-bit activation masks and one-shot lock bits); all 64 CD track flag words (remembered one-shot bits and pending countdown bytes); every fixed camera's flags word (preserving one-shot locks); active flip effect ID and flip timer; global **Monk hostility flag**. |
| **Placed level items — persistence classes** | **Established (static).** Every authored placed item persists only the state subsets enabled for its object family:<br>• **Position & motion** (position, rotation, room, horizontal speed, fall speed): Lara, all intelligent creatures (except stationary moray eels), vehicles (Boat, Snowmobile, Armed Snowmobile, Snowmobile Rider), pushable blocks (`67..70`), rolling boulders (`101`, `117`, `118`), collapsing/falling blocks (`60..62`), movable traps (spiked wall, ceiling spikes, rolling blades, icicles, zip-line handle, falling ceilings, darts, lift), Dragon front and back, Winston, and all pickups/keys/puzzles/dragons (so creature-dropped cargo retains its drop coordinates). On restore, updates room membership and refreshes resting floor height for shadowed items.<br>• **Animation** (current state, goal state, required state, clip number, frame number): Lara, all creatures (including moray eels, Bartoli, Dragon halves, Winston), doors (`106..113`), hinged trapdoors (`114..115`), drawbridge (`63`), switches/levers/buttons (`93`, `103..105`), pushable blocks, traps/blades/pendulums/teeth/boulders/collapsing tiles/zip line/statue blade, detonator box (`227`), boats, snowmobiles, lift, breakable windows (`72..73`), gondolas, shootable bells.<br>• **Hitpoints**: Lara and all targetable creatures (including moray eels, Armed Snowmobile, Dragon front; excludes untargetable Winston, Dragon back, Bartoli, and non-creature objects).<br>• **Status, flags & timer** (active bit, 2-bit status, gravity bit, collidable bit, 5-bit trigger mask, one-shot/reverse/invisible/cleared-corpse bits, countdown timer): all stateful interactive, creature, trap, door, switch, socket, pickup, flame-emitter, combat-end, and vehicle items. On restore, an item marked as a cleared corpse is immediately killed and disabled; otherwise active items resume per-tick updates, status/gravity/collidable are restored, and dead cleanup-eligible corpses (not yet cleared) are re-registered as eligible for Clear Bodies cleanup. |
| **Creature AI & carried drops** | **Established (static).** For every intelligent creature: persist the pickup(s) carried by that creature to drop on death (preserving multi-item drop order); if the creature currently has active AI state, persist its head rotation, neck rotation, maximum turn rate, creature internal flags, and AI mood. On restore, reactivate its AI state (bypassing normal active-AI capacity eviction if full) with those 5 parameters; pathfinding navigation state is reinitialized fresh rather than persisted. |
| **Type-specific extra state & restore rebuilds** | **Established (static).** Dedicated extra state and post-restore world rebuilds:<br>• **Pushable blocks (`67..70`):** on restore, first undo the authored startup floor raise (`+1024`), restore saved position and status, and if resting inactive (status `0`), reapply the `−1024` floor raise and navigation-box closure at the restored tile.<br>• **Puzzle sockets (`182..185`):** if restored status is active or disabled, swap object type to the matching completed puzzle model (`186..189`).<br>• **Collected pickups, keys, puzzles, dragons:** if restored status is disabled, remove from the room's visible/drawn items so collected pickups are neither drawn nor collectable again.<br>• **Breakable windows (`72`, `73`):** if restored flags include the invisible bit, set mesh visibility mask to `0x100` (shattered frame).<br>• **Aquatic mines (`222`):** if restored flags include the invisible bit, set mesh visibility mask to `1`.<br>• **Speedboat (`14`):** persist full hull dynamics (turn velocity, left/right bow fall speeds, tilt angle, extra yaw rotation, tracked water height, engine pitch).<br>• **Player Snowmobile (`13`):** persist full vehicle dynamics (track mesh animation state, turn velocity, left/right ski fall speeds, tilt angle, extra yaw rotation, engine pitch).<br>• **Snowmobile Rider (`51`):** if restored status is disabled, convert its paired vehicle item into a rideable player Snowmobile (`13`) and initialize snowmobile dynamics.<br>• **Lift (`65`):** persist both lift state integers (starting/target heights and wait state).<br>• **Dragon (`203`):** if restored status is disabled (slain by pulling the Dagger of Xian), rebuild its skeletal remains at `Y − 1010`.<br>• **Active thrown world flares (`152`):** count all active dynamically spawned world flares (beyond placed level items) and persist each flare's position, orientation, room, horizontal speed, fall speed, and remaining burn age. On restore, recreate active dynamic flare items with their saved motion and remaining burn age. |

### Transient / non-persisted state (explicitly NOT saved in retail PC)

| State | Retail PC reload behaviour |
|---|---|
| **Live camera state** | **Established (static).** Camera eye/target coordinates, active mode, bounce/shake amplitude, fixed-camera countdown timer, and look subject are **not** saved. On reload, the camera re-initializes behind Lara in chase mode (except fixed-camera one-shot flags, which *are* persisted, and active extra-animation mode which preserves cinematic camera mode). |
| **Non-flame effects & dynamic lights** | **Established (static).** Transient visual effects (blood splats, splashes, bubbles, ricochets, explosions, gun flashes, debris) and dynamic point lights are **not** persisted (only Lara's burning flame is recreated from her burning flag, and triggered flame emitters spawn fresh flames on their next active tick). |
| **In-flight player and enemy projectiles** | **Established (static).** Dynamically spawned harpoon bolts, grenades, thrown knives, and enemy flame missiles are **not** persisted (unlike dynamically spawned world flares). |
| **Random number generators** | **Established (static).** Neither the gameplay RNG state nor the draw RNG state is saved or restored. |
| **Sunset progress timer** | **Established (static).** In retail PC `Tomb2.exe`, the progressive sunset timer (`Bartoli's Hideout`) is **not** persisted and resets to `0` on reload (advancing anew from `0` after loading a save). |
| **Assault course timer & best times** | **Established (static).** Lara's Home cannot be saved; assault-course best times exist only in volatile session memory in retail PC. |
| **Ambient & one-shot CD playback** | **Established (static).** Loading a save restarts the level's configured looping ambient track (if nonzero); any one-shot floor-triggered track that was mid-playback when saving does not resume mid-track (though its one-shot flag bits remain recorded in the 64 track flag words). |

## Scope limits and open edge cases

- **Static PC evidence only:** All rules, script tables, thresholds, formatting formulas, and persistence classes above are established statically from the pinned retail PC `Tomb2.exe`, `TOMBPC.DAT`, and `TITLE.tr2`. No live playthrough capture, save/load round-trip test, or PlayStation parity check was performed (note in particular that PlayStation retail Tomb Raider II uses different memory-card save limits and front-end flows).
- **Surface death animation entry:** While `HP ≤ 0` on land (`state 8`), underwater (`state 30`), and in vehicles (speedboat/snowmobile) was verified individually, the exact transition animation clip used if Lara takes fatal damage specifically while treading on the water surface (without submerging) was not separately traced against a live capture.
- **Unexercised script events:** Retail PC `TOMBPC.DAT` defines zero standalone picture entries and never emits picture (`0`), jump-sequence (`8`), or loading-picture (`12`) events; their runtime behaviour is inert in retail PC `Tomb2.exe`.
